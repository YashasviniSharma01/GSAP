# GSAP 

This repository is a collection of small GSAP animation demos built to explore motion design, SVG path manipulation, and ScrollTrigger effects.

## Overview

The project contains a few front-end experiments using HTML, CSS, and JavaScript with GSAP for animation. Each folder demonstrates a different animation concept:

- `css curves` — curved layouts and visual wave-like design using CSS
- `scrollTrigger` — horizontal motion tied to scroll progress using GSAP ScrollTrigger
- `svg` — interactive SVG path animation based on mouse movement

## Features

- Smooth GSAP-based animations
- Scroll-driven motion with `ScrollTrigger`
- SVG path editing and animation
- CSS-based curve and wave styling
- Lightweight static HTML/CSS/JS project

## How to run

Because this is a static demo project, you can open any of the `index.html` files directly in a browser.

For example:

- `css curves/pure css/index.html`
- `scrollTrigger/index.html`
- `svg/index.html`

You can also run a local server if you prefer:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```
